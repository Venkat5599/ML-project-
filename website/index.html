Frequently Asked Questions

A temporal, graph-aware hybrid machine-learning framework that flags suspicious Bitcoin transactions in the Elliptic dataset, explains each flag, and serves the results through a local investigation app. It is a Machine Learning Laboratory course project.

The Elliptic Bitcoin dataset: 203,769 transactions, 234,355 directed flows, 49 two-week time steps and 165 anonymised features. 42,019 are labelled licit, 4,545 illicit and 157,205 unknown.

Chronologically. Models train on time steps 1-29, hyperparameters and ensemble weights are tuned on 30-34, and the test window 35-49 is evaluated once. Metrics are precision, recall, F1, average precision, ROC-AUC and precision/recall at 50, 100 and 250 alerts.

Tuned XGBoost is the strongest single ranker: AP 0.801 and precision 1.0 across the top 100 alerts. The XGBoost + GraphSAGE blend has the best F1 at 0.818 with the same top-of-queue precision.

Partly. GraphSAGE alone reaches AP 0.679, below XGBoost, but its top 100 stay 99% pure, and blending it in gives the best F1. Hand-built topology features add nothing, because the dataset's 72 aggregated features already encode one-hop structure.

Because it leaks the future. The same pipeline scores AP 0.986 on a random split and 0.801 on the chronological one. The lower number is the honest one, and it is the one reported.

No. The output is a suspicion ranking for human review. Labels come from the dataset's attribution and are incomplete; unknown transactions are scored but never treated as ground truth.

Install the Python requirements, download the dataset from the HuggingFace mirror (about 700 MB, no login), then run the experiment scripts in order. The README lists every step, and the investigation app runs locally with a FastAPI backend and a Next.js frontend.
